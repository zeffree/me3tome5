# me3tome5

Interactive simulator that compares **Microsoft 365 E5** vs **M365 E3 + a competitive best-of-breed stack** to match E5 capabilities.

## Features
- Live cost computation for any user count, term (1/3/5 yr), and negotiated discount
- ~70 vendors curated from the latest **Gartner Magic Quadrants** (EPP 2025, Email Security 2024, Access Management 2024, SSE 2024, Analytics & BI 2024, UCaaS 2024, Enterprise Information Archiving 2024, DSPM 2025) — each tagged Leader / Challenger / Visionary / Niche Player
- Side-by-side line-item breakdown
- Annual cost chart + Option B spend mix doughnut
- Capability parity matrix (Yes / Partial / No) with gap notes
- Light & dark themes (auto-detects OS preference, persisted)

## Use
Just open `index.html` in any modern browser. No build, no server.
